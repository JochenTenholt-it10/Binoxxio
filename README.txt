Binoxxo – Logikrätsel (PWA-Edition)
====================================
Autor:   it10
Version: 2026.11

Enthaltene Dateien:
- index.html            Hauptseite mit "Autor: it10 | Version: 2026.11" als erster Überschrift (<h1>)
- style.css             Design, Dark Mode & A4-Druckansicht
- app.js                Spiellogik, Generator, Timer, Statistik & Service-Worker-Registrierung
- manifest.webmanifest  Web-App-Manifest für die Installation als App (PWA)
- icon.svg              Vektor-App-Icon für Homescreen und Desktop
- sw.js                 Service Worker für Offline-Nutzung (bei Betrieb über HTTP/HTTPS)
- README.txt            Diese Dokumentation

Hinweise zur Nutzung:
- Lokal im Browser: Einfach index.html per Doppelklick öffnen.
- Als Web-App (PWA) installieren: Den Ordner über einen Webserver (z. B. GitHub Pages,
  Netlify oder lokal per `python -m http.server`) bereitstellen und im Browser
  "Zum Startbildschirm hinzufügen" / "App installieren" wählen.
